About the Project
Deep Weighted Unsupervised Optimized Deep Belief Network (DWU-ODBN) for Anomaly Detection in IoT-Enabled Multimedia Communication Systems
Project Overview

The proposed DWU-ODBN model is designed to detect anomalies in IoT-enabled multimedia communication systems. It focuses on modeling complex patterns within high-dimensional multimedia traffic data (including video, audio, and sensor streams) collected from IoT devices.

Objectives:
  • 1. Design a DWU-ODBN model: Develop a deep weighted unsupervised optimized deep belief network to identify anomalies in IoT multimedia environments by capturing non-linear dependencies in complex data.
  • 2. Enhance security and efficiency: Integrate adaptive weight assignment and optimization mechanisms within the DWU-ODBN framework to reduce false positives and improve detection accuracy.
  • 3. Preprocess heterogeneous data: Transform and standardize video, audio, and sensor data into suitable input representations for deep learning-based anomaly detection models.
  • 4. Evaluate system performance: Assess the proposed system on benchmark multimedia IoT datasets using metrics like accuracy, detection rate, false alarm rate, and computational overhead — and compare with existing baseline techniques.
Expected Outcome:

The DWU-ODBN system aims to deliver a robust, scalable, and intelligent solution for real-time anomaly detection in IoT-driven multimedia networks, strengthening data security and operational reliability.
