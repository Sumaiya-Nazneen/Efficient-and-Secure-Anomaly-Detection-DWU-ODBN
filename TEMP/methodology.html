Methodology
In-depth review of algorithms, model architecture, and evaluation strategies applied across diverse anomaly detection domains: Network Traffic, Windows OS, and IoT Devices.

Network Traffic Anomaly Detection

Using flow-level metadata, including protocol, ports, packet counts, and flags, the model employs the Dual Weight Dense (DWU ODBN) architecture to uncover subtle network attack patterns such as DDoS, scanning, and injections.

Batch normalization and dropout layers are employed to prevent overfitting. The model outputs predictions leveraged to trigger real-time alerts and act as a foundation for threat intelligence.

Windows Operating System Anomaly Detection

By analyzing system logs, process activity, and performance counters, this approach utilizes a neural network with the DWU ODBN layer to distinguish normal Windows behavior from malicious anomalies like backdoors, ransomware, and credential theft.

Regularization techniques improve generalization and help handle the variability of diverse Windows environments and attack vectors.

Internet of Things (IoT) Device Anomaly Detection

Given the diversity of IoT devices, sensor streams and device communication patterns are leveraged with sequential modeling and the custom dual-weight architecture to detect unusual behaviors and potential security breaches.

This model is designed to adaptively learn from time-series data and categorial device states to enhance resilience against evolving threats.
